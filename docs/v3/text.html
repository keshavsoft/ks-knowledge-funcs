Typography & Styling Token Registries

Junior developers don't need to guess Tailwind classes for table formatting. Use our central token map (PREDEFINED_TEXT_CLASSES.json) to format header text, numeric currency columns, bold totals, badges, and muted notes!

table.head.primary Header Typography Token

Used for primary data table header titles with bold uppercase font and dark text contrast.

Rendered Output: INVOICE NUMBER 
<ks-table-cell-content-common
  options='{"theme": "table.head.primary"}'>
</ks-table-cell-content-common>
table.cell.numeric Numeric Cell Token

Aligns currency values right and uses tabular monospaced numbers for clean vertical alignment.

Rendered Output: ₹1,45,890.00 
<ks-table-cell-content-common
  options='{"theme": "table.cell.numeric"}'>
</ks-table-cell-content-common>
table.foot.summary Footer Summary Token

Used for summary footer rows and grand totals with heavy bold weight and accent color.

Rendered Output: Grand Total: ₹5,98,400.00 
<ks-table-cell-content-common
  options='{"theme": "table.foot.summary"}'>
</ks-table-cell-content-common>
table.cell.badge Status Badge Token

Renders compact pill badges with rounded borders for status indicators like Paid, Pending, or Active.

Rendered Output: APPROVED ✓ 
<ks-table-cell-content-common
  options='{"theme": "table.cell.badge"}'>
</ks-table-cell-content-common>
table.cell.muted Muted Subtext Token

Used for secondary metadata notes, timestamps, or system reference codes with reduced visual weight.

Rendered Output: Last updated 2 minutes ago by System Administrator 
<ks-table-cell-content-common
  options='{"theme": "table.cell.muted"}'>
</ks-table-cell-content-common>
