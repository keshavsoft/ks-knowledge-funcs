Architectural Philosophy

Separation of Concerns (SOC): High-Level vs Atomic

SOC Principle Verified ✓

Why didn't we put all cell-rendering code inside jsTableBuilderViews? Because a good system separates concerns! `jsTableBuilderViews` handles high-level layout orchestration (Tables, Forms, Cards), while `ks-web-components` owns the core atomic HTML building blocks.

1. Higher-Level Orchestrator jsTableBuilderViews

Coordinates table grids, vertical filter forms, sorting algorithms, dynamic row filtering, and target DOM node refreshing.

2. Core Atomic Building Blocks ks-web-components

Renders atomic custom element tags (<ks-table-cell-content-common>), inputs, buttons, dropdowns, date pickers, and Tailwind CSS design tokens.
