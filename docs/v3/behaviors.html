Story 3

Native HTML Control Behaviors & Validation

Test how junior developers can activate browser-native input features (autofocus, native tooltips, tabIndex: -1, spellcheck controls, and minlength validation) instantly via JSON options.

Part 1

Autofocus & Auto-Focus Control

Focuses the input element automatically on page load without needing manual JavaScript focus() calls.

<ks-table-cell-content-common
  options='{"controlType": "text", "autofocus": true}'>
</ks-table-cell-content-common>
Part 2

Tab Navigation Exclude (tabIndex: -1)

Excludes the input control from sequential keyboard Tab navigation while remaining mouse clickable.

<ks-table-cell-content-common
  options='{"controlType": "text", "tabIndex": -1}'>
</ks-table-cell-content-common>
Part 3

Native Hover Tooltip (Title Attribute)

Renders standard browser-native hover tooltips via title attribute without heavy tooltip JS libraries.

<ks-table-cell-content-common
  options='{"controlType": "text", "title": "Tooltip Active!"}'>
</ks-table-cell-content-common>
Part 4

Native Minimum Length Validation (minlength)

Enforces browser-level form validation requiring a minimum character count before form submission.

⚠️ Type less than 5 characters and click submit below to see native browser validation popup! 
<ks-table-cell-content-common
  options='{"controlType": "text", "minlength": 5, "required": true}'>
</ks-table-cell-content-common>
