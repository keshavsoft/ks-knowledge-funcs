Story 2

Button Styles, Themes & Safe Event Pipelines

Junior developers don't need to write manual event listener loops or fragile handling logic. Pass your theme string and callback function inside options — our component handles styling, hover states, and safe error wrappers automatically!

primary Primary Solid Theme

High-visibility primary action button with indigo theme gradient and shadow focus glow.

Rendered Output: 
<ks-table-cell-content-common
  options='{"showButton": true, "theme": "primary"}'>
</ks-table-cell-content-common>
success Success Confirm Theme

Used for positive confirmation actions like Approve, Submit, or Mark Paid.

Rendered Output: 
<ks-table-cell-content-common
  options='{"showButton": true, "theme": "success"}'>
</ks-table-cell-content-common>
danger Danger Destructive Theme

Used for destructive actions like Delete Record, Cancel Order, or Revoke Access.

Rendered Output:

</ks-table-cell-content-common>
