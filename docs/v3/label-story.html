The Primitive Anchor

The Full Story of the Primitive <label> Control

Before building giant tables or complex forms, let's master the most fundamental primitive control on the left side of every input: The <label> Element. Discover how <ks-table-cell-content-common> handles label text, typography tokens, required indicator badges, accessibility, and positioning!

Story Part 1 Accessibility & Semantics

1. Semantic Binding: Label + Input Pair

A label isn't just text. It provides human context to the input control on its right. When bound via for="fieldId", clicking the label automatically focuses the input box! 

<ks-table-cell-content-common
  options='{"label": "Customer Voucher Number", "id": "demo-input-1"}'>
</ks-table-cell-content-common>
Story Part 2 PREDEFINED_TEXT_CLASSES.json

2. Label Styling & Typography Tokens

Our central styling token map exports 6 distinct label themes (vertical.text.*) for standard fields, primary accents, alert fields, and large headers.

Story Part 3 Required Indicators

3. Automatic Required Asterisk Badge (*)

When required: true is passed in options, the label automatically renders a sharp red asterisk badge (*) notifying the user that the field is mandatory! 

<ks-table-cell-content-common
  options='{"label": "Stock Item Name", "required": true}'>
</ks-table-cell-content-common>
